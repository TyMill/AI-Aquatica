# Example real water-quality dataset

This directory contains the real water-quality CSV file used by `examples/real_dataset_workflow.py` and by the SoftwareX illustrative example.

The dataset was generated by Tymoteusz I. Miller during laboratory-based water-quality analyses and is included with the software to make the illustrative workflow fully reproducible.

The file intentionally preserves the original regional CSV conventions used in many Central European monitoring exports:

- semicolon-separated values,
- comma decimal separator,
- Central European text encoding.

AI-Aquatica uses this file to demonstrate robust CSV format detection, water-quality column normalization, hydrochemical charge-balance diagnostics, machine-learning workflows, and standalone HTML report generation.
